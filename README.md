# FoodFlow

A full-stack food delivery CRUD application built using
Next.js 16, TypeScript, MongoDB and Tailwind CSS.

## Features

- User registration and login
- JWT authentication
- HTTP-only authentication cookies
- Role-based authorization
- Admin dashboard
- Food CRUD
- Food search/menu
- Shopping cart
- Increase/decrease food quantity
- Checkout
- Order creation
- Customer order history
- Admin order management
- Order status management
- Server-side price verification
- Zod input validation
- Responsive UI

## Technology Stack

- Next.js 16
- TypeScript
- MongoDB
- Mongoose
- Tailwind CSS
- JWT
- Zod

## Security

- JWT authentication
- HTTP-only cookies
- Role-based authorization
- Server-side validation
- MongoDB validation
- Server-side price calculation
- Protected admin APIs
- Environment variables for secrets
